= How to Manage {app-short-name} access

== Introduction

This section provides the steps required to authenticate to the {app-short-name}.

To perform any operation on the {app-short-name}, you must be previously authenticated using
altiplano user credentials.

== How to Authenticate

To authenticate and use {app-short-name} REST APIs, an access token is required.

[NOTE]
====
The generated access token must be included in the HTTP header as a Bearer authentication header when executing
any {app-short-name} operation through the {app-short-name} REST APIs.
====

=== Authenticating as an altiplano admin
The token can be retrieved using the following information:

- Admin username
- Admin password
- Client ID
- Client secret

==== Get Token using CURL

.Usage
[source, bash, subs=attributes]
----
curl -k --location 'https://{altiplano-host}/altiplano-sso/realms/master/protocol/openid-connect/token' \
--header 'Content-Type: application/x-www-form-urlencoded' \
--data-urlencode 'grant_type=password' \
--data-urlencode 'client_id=$CLIENT_ID' \
--data-urlencode 'client_secret=$CLIENT_SECRET' \
--data-urlencode 'username=$USERNAME' \
--data-urlencode 'password=$PASSWORD'
----

==== Get Token using Postman

The steps to retrieve a token from Postman are as follows:

. Create new request
. Go to *Authorization* tab:
+
image::authenticateSection_obtainToken.png[align="center"]

. Enter the next required data:
+
--
- Select the Grand type = "Password credentials".
- Access Token URL: The Altiplano keycloak token url. For example: https://{altiplano-host}/altiplano-sso/realms/system/protocol/openid-connect/token
- Client ID: The id of the client in keycloak.
- Client Secret: The secret of the client. This can be found under the "credentials" section of the client details in keycloak
- Username: admin's username
- Password: admin's password
--

. Click the *Get New Access Token* button
+
image::authenticateSection_obtainToken2.png[align="center"]

. The generated token was generated. Click the *Use Token*:
+
image::authenticateSection_obtainToken3.png[align="center"]

. The generated token can be copied from *Token* field.
+
image::authenticateSection_obtainToken4.png[align="center"]
